# Replay and corpus scope

`python evals/run.py --suite ai-replay --split development --output artifacts/ai-replay` executes explicit no-assistant and deterministic-rules protocol baselines. `evals/ai.py` exports `grade_proposal(task, proposal)` for the B.3 boundary and `grade(task, response)` for the D3 service envelope. Unknown fields, stale revisions/hashes/selection, fabricated measurements, unauthorized parameters/units, nonfinite/coerced values and automatic application fail closed. Critical violations cannot be hidden by averages. The 12 seed decision cases cover measured intervention, no-op, missing/invalid/stale evidence, ambiguity, infeasibility, timeout/rate limit and three injection surfaces. They are authored regression fixtures, not a statistically representative task corpus.

Reference responses are protocol fixtures. Their placeholder preview identities do not represent rendered audio. Baseline replay measures response contracts only, never audio improvement or model competence. Single model without tools, tool-grounded model and grounding-disabled ablation remain explicitly blocked until approved provider/snapshot, budget and actual captured runs exist. Live runs must retain all outcomes and repeat each original task three times. Bootstrap confidence intervals cluster by original task; paired differences use the same tasks. All replay records explicitly account for zero model tokens/cost and unavailable model latency. Provider calls require their actual usage, elapsed time, timeout and failure outcomes.

`evals/datasets/seed-inventory.json` freezes task and synthetic fixture identities. Its canonical digest is pinned in `manifest-lock.json`; edits require a deliberate corpus/baseline review. Stable hash buckets assign splits by original group, inherited by gain variants. Validation rejects cross-split parent, exact-hash and aligned normalized-signature duplicates. This signature catches gain/polarity variants only; it does not replace recording provenance or general audio similarity review. Two licensed public DI recordings now provide functional regression evidence (see `public-corpus.md`). Broader musical coverage, independent holdout ownership and a final sequestered unseen test set remain unqualified. Inspectable locked-test seeds are regression fixtures, so `holdout_qualified` is false.

Raw process stdout/stderr, argument arrays, return codes and timeout records are retained alongside case evidence. No model text is executed as a shell command. Tests deliberately corrupt critical proposal fields and require the actual grader to reject them. They establish evaluator sensitivity, not product tool authorization, human preference, hardware timing or licensed-data qualification.
