# Embedded React frontend

The frontend is bundled into the native executable using JUCE 9's resource provider. It has no production localhost server, filesystem browser APIs, remote fonts, CDN, analytics or audio processing. React owns presentation; JUCE owns audio, file pickers, session validation, rendering, device access and exports. The existing bounded audio command queue remains the only real-time control handoff.

Build with Node 24 and `npm ci --ignore-scripts`, `npm run typecheck`, `npm test`, `npm run build` from `apps/frontend`. Include `apps/desktop/Frontend.cmake` from the root after creating ToneScope, and remove its prior `JUCE_WEB_BROWSER=0` definition. The CMake include bundles fixed generated asset filenames. Windows needs WebView2 runtime; unsupported backend falls back to the original native interface. `--demo --screenshot` deliberately preserves the native snapshot smoke because native child browser windows are not included in JUCE component snapshots.

The only native function is `tonescopeCommand({version:1,action,...payload})`, resolving a message-thread snapshot. Commands are whitelisted in WebFrontend.inc and validate primitive types/ranges. File actions launch native choosers; no command accepts a filesystem path or executable. Browser navigation is restricted to JUCE's resource origin. The browser gets source basename, graph/render revision, bounded control metadata, selection fractions and actual measured traces. Snapshot polling has one request in flight and an eight-second timeout. Changes pass through existing native callbacks and rendering invalidation.

Commands include snapshot, import, open, save, export/export.selection, devices, play, pause, rewind and capture; boolean live/loop/match; bounded mode/order/stage/quality/band/parameter/selection/seek controls. Manual microscope marks and profile enable/reset/export are native-owned. Assistant ask/cancel/preview/audition/apply/dismiss/history-delete actions use a strict internal payload after removing the validated version/action envelope. It uses the optional authenticated local broker, actual native candidate measurements, frozen baseline/candidate RMS comparison and explicit whole-patch acceptance/undo. Missing Node/runtime remains an explicit service-unavailable state. Rejected commands preserve engine settings.

Dark-first instrument surfaces put measured waveform and logarithmic spectrum at the center. Muted sage is the dry reference, warm amber the processed signal; labels and dashed spectrum distinguish traces beyond color. Numeric entry accompanies every shadcn/Radix slider. Motion uses MotionConfig reducedMotion=user, CSS answers reduced motion/transparency, increased contrast and forced colors. Browser checks cannot qualify Narrator, physical interfaces or human listening.

Font curation: [Space Grotesk](https://www.freefaces.gallery/typefaces/space-grotesk) and [Commit Mono](https://www.freefaces.gallery/typefaces/commit-mono). Space Grotesk variable TTF from [Google Fonts upstream](https://github.com/google/fonts/tree/main/ofl/spacegrotesk); Commit Mono regular OTF from [author upstream](https://github.com/eigilnikolajsen/commit-mono/tree/main/src/fonts/fontlab). Both redistribution licenses are bundled in public/fonts. Fonts are unmodified. shadcn Button/Slider/Switch/Tabs source was downloaded from the [official new-york registry](https://ui.shadcn.com/r/styles/new-york/button.json), with local import paths. Its [MIT license](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md) is retained alongside components.

Design references read: apple-look accessibility/layout/typography/color/designing-for-macos and cross-platform translation, plus buttons/sliders/keyboards/dark-mode; apple-motion fluid interfaces, physical interruption, optional motion and material accessibility. Platform shell stays native Windows. Explicit dark-first user choice governs appearance. Human screen-reader and listening assessment remains external qualification.

Browser-only verification fixture: /tests/fixture.html on the development server provides explicitly labeled synthetic signals and a JUCE protocol double. It is excluded from the production entry point and bundled resource allowlist. It verifies UI interactions, not native engine execution, audio hardware or model quality.
