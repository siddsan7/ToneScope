# Headless DSP definitions

The C++20 Engine is host-independent; prepare/reset happen outside processing. One processing thread owns parameters and state. Callback has fixed two-channel stack state and performs no allocation, IO, locking or logging. `setParameters` is a control-boundary operation and throws on invalid input, retaining the last valid parameters. Call it outside process; callers must serialize it with process. Input NaN/Inf becomes zero; input outside +/-16 clamps and increments invalidSamples. Finite stage output is retained without monitoring limiting; a catastrophic nonfinite or >1e12 internal value mutes and increments the same counter.

All continuous controls use a 15 ms one-pole in their declared units, coefficient exp(-1/(.015*sampleRate)). Stage enable/order switch immediately; these discrete changes are not click-free and should occur while stopped in this initial core. reset snaps controls to targets and clears history. Offline render always starts from source frame zero. No short-preroll approximation is used. Latency is zero at 1x and 32 source samples for enabled 2x/4x drive; causal filters additionally have frequency-dependent phase/group delay. See `microscope.md`.

Compressor: linked mean squared channel energy, 10 ms one-pole RMS integration. Level is 10 log10(max(energy,1e-30)). Positive gain reduction has slope 1-1/ratio with quadratic soft knee; outside knee use zero or slope*(level-threshold). Attack/release smooth reduction in dB with exp(-1/(timeSeconds*rate)); time means 63.2% of a step. Makeup is explicit. Ratio 1/makeup 0 is identity. Channel averaging links stereo; opposing polarity does not cancel detector energy.

EQ: RBJ low shelf 120 Hz, bell (20..min(20000,.45*rate), Q .2..10), high shelf min(6000,.4*rate). Shelves use S=1. On each sample where smoothed EQ parameters changed, normalized stable coefficients are designed once per filter and shared by both channels; unchanged controls reuse cached coefficients. Direct-form II transposed states remain independent per channel. This avoids interpolating coefficients; pathological rapid modulation still needs qualification.

Drive: pre-emphasis x + .25*(x-xPrevious); drive 0..36 dB; tanh transfer; one-pole post-tone at 20..min(20000,.45*rate); 20 Hz DC blocker. Output trim applies after all stages. Drive supports 1x/2x/4x processing with finite FIR resampling and possible residual aliasing. The compressor, tone-EQ coefficient and biquad graphs, and tanh transfer are compiled from authored Faust with pinned Faust 2.88.0 and actually used in the native Engine. `dsp/generated/manifest.json` records provenance; `faust-stages.md` defines exact ownership. Surrounding drive, crossover and resampling filters remain C++20.

Float32 WAV export preserves actual processed values including overload >1. Eager PCM16/24/32 and float32 RIFF WAV import is limited to 256 MiB; RF64 and extensible WAV are unsupported. `WavStreamReader`/`WavStreamWriter` provide a separate bounded 2 GiB/two-hour path used by the CLI and persistent capture. Invalid/nonfinite data rejects; metadata chunks are bounded and padding is required. readWav does not sanitize amplitude: Engine ingress owns that policy.

Comparison uses exact [start,end) channel energy, requires >=2 frames and equal rate/shape, and reports sample peak of gain-adjusted wet. RMS matching rejects either branch below 1e-9 amplitude (-180 dBFS), freezes one gain and caps at +/-12 dB. Raw residual is wet-dry; matched residual is gain*wet-dry. Analysis assumes already aligned source history and does not infer revisions. Silence raw comparison is valid; silence matching is invalid.

Spectrum returns linear peak amplitude bins from a periodic Hann window, power-of-two size 16..65536 (default 2048), coherent normalization sum(window), one-sided doubling excluding DC/Nyquist. Stereo channels are transformed independently, then combined as RMS magnitude per bin, preserving anti-phase energy. Mono coherent-amplitude calibration remains unchanged. No temporal smoothing, noise floor or hop scheduling is applied by this synchronous analysis API. Source sample index is supplied explicitly. Analysis never executes in the callback.
