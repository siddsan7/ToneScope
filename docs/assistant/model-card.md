# Model card

The pinned Eve 0.80.1 scaffold model remains `openai/gpt-6-luna-fast` with high reasoning. That name is configuration inherited from the scaffold, not a claim about availability, pricing, quality or qualification. No live provider was invoked or evaluated.

The default runnable broker selects RulesProvider, a deterministic offline level baseline. It uses current measured RMS, a host-authorized outputDb control, a target of -18 dBFS, a maximum adjustment of six decibels, and measured peak headroom when available. Quieter requests decrease gain. Silence below the declared -180 dBFS floor abstains. Ambiguous or unsupported tonal requests abstain; a level already near target or constrained by range/headroom is noop. It does not infer tone quality, diagnose instruments, hear audio, or select topology. Real native preview measurements accompany a ready result.

Provider is an explicit injection interface. GatewayProvider is an actual dormant AI SDK implementation, using generateText plus strict structured output and the same bounded tool coordinator. It is instantiated only when TONESCOPE_ENABLE_LIVE=1, a private manifest live configuration grants consent and a positive USD budget, and AI_GATEWAY_API_KEY exists. The verified model identifier is chosen explicitly in that configuration; the scaffold remains unchanged. The adapter fetches current Gateway model metadata before any billable attempt and rejects a missing model or prices above the configured verified ceilings. A single configured provider slug is allowed, model fallback is empty, SDK retries are zero, and provider-side structured output is required. No live call was executed in this implementation work.

The adapter reserves a conservative UTF-8 text-byte bound plus framing for input tokens and a finite completion-token ceiling before every billable call. Provider-reported usage replaces the reservation only after a successful response; failures or missing usage retain the upper bound. USD is calculated from reported tokens and the freshly checked configured price ceilings, so it is a conservative computed cost rather than an invoice reconciliation. Each request reserves its full token-price maximum in a persistent cumulative budget ledger before entering the provider. Successful requests settle the reservation; crashes retain it. An exclusive ledger lock prevents concurrent processes from losing reservations. A crash can leave a lock that requires trusted host recovery after confirming the original process ended. The ledger is preserved when deleting conversation history. Actual usage exceeding a reservation fails the request and is recorded as an overrun; subsequent spending is blocked.

A dated verified snapshot must be no older than one day. The model receives only request text, opaque native metadata, typed controls and measured numeric evidence. The host automatically compares a rendered candidate before another model step, and final proposals pass independent coordinator revision/evidence/preview validation. A mock AI SDK model verifies real SDK structured-response parsing, accounting, metadata rejection, no-retry failure behavior and tool dispatch. This is protocol infrastructure evidence, not model quality. External provider-backed corpus qualification, current model availability/pricing confirmation under user credentials, retention-policy confirmation, invoice reconciliation and human listening remain unperformed.

Eve tool integration is compiled against installed versioned documentation. All five tool wrappers and the inert sandbox provider build. Compiled integration and deterministic/native software checks do not qualify model behavior. Live task success, abstention, hallucination and cost/latency intervals remain blocked pending an explicitly authorized, priced, provider-backed corpus run. Replays and fixture expected patches count only as protocol/security evidence.

Renderer limitations follow the native engine mode and selected source. Actual processing starts at source zero to preserve history; the 30-second cap charges this work plus alignment, not only exported selection duration. A short crop late in a source can therefore be refused. No hardware, human listening, accessibility, licensed-corpus, or model-quality evidence is claimed.

Streaming baseline evidence may come from native exact selected full-band RMS/peak aggregates when the selected audio exceeds the bounded inspection cache. The private aggregate binding includes the source and graph hashes, revision, selection, session and rate; candidates still use the actual native renderer and independent readback. A residual is not reported without actual cached baseline audio. Audition uses verified cropped candidate files through the native bounded ring; this software verification does not establish listening quality.
