# Data card

Raw audio stays in host-selected local assets and private local native previews. Raw audio never enters GatewayProvider messages. Its explicit live mode sends only user request text, opaque metadata, typed controls and numeric evidence to the authenticated AI Gateway; this requires configured consent and budget. The model-facing snapshot contains opaque source handles, hashes, revision, selection, sample rate and allowed controls; it has no filesystem paths. Native subprocess stdout is parsed, bounded and reduced to numeric measurements and opaque preview metadata.

The private native manifest, CLI executable, source/baseline paths, work directory and token are trusted host configuration. Runtime directories, dependencies, generated builds and environment files are ignored. Operators must select a private per-user directory and preserve OS ACL protection; a bearer token does not protect a compromised native host account.

History writes a same-directory unique temporary file followed by atomic rename. Session/request filenames are SHA-256 digests. Stored results retain structured proposals, evidence, previews, usage and trace IDs; prompts are never stored. Free-form proposal narratives and response reasons are redacted before persistence. Request text can exist in memory for the request lifetime. No raw provider traces or audio are stored in history. GET returns the redacted history, so natural-language rationale is available only on the original response. Atomic rename failure fails the request visibly; no claim of persisted success is made.

Session deletion cancels work, removes that session's history files and known preview directories, and prevents an active late result from recreating them. A new session needs a new host-owned identity. Runtime crashes may leave temporary files or previews whose ownership map was lost; the native host must remove its private work directory on application/session teardown. This is a limitation, not a claim of comprehensive forensic erasure.

Tests generate a synthetic floating-point mono sine locally, render it with the actual native CLI and independently check proposal/audio hashes and measured improvement. Mock adapters exercise security, cancellation, stale revisions, caps, persistence and failures. The dormant Gateway adapter was tested through a local mock AI SDK model only. No licensed instrument corpus, recorded person, external provider transcript or human rating was used. The synthetic test validates software integration only.
